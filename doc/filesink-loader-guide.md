# HDB++ FileSink Loader Guide

This guide explains how to load CSV files generated by the HDB++ FileSink into TimescaleDB using PostgreSQL's COPY command.

## Overview

The FileSink generates CSV files ready for bulk loading:
- Files ending in `.csv` are complete and ready to load
- Files ending in `.csv.current` are still being written (do NOT load these)
- Each file corresponds to a specific table and epoch

## Prerequisites

1. TimescaleDB database with HDB++ schema installed
2. PostgreSQL user with appropriate permissions
3. Access to the CSV files (either local or server-side)

## Loading Methods

### Method 1: Single File Load (Local)

Load a specific CSV file from the client machine:

```sql
-- Connect to your HDB++ database
\c hdbpp

-- Set NULL representation to match FileSink output
\pset null ''

-- Load a single file
COPY att_scalar_devdouble (att_conf_id, data_time, value_r, value_w, quality, att_error_desc_id, details)
FROM '/path/to/att_scalar_devdouble__20260209T200000Z.csv'
WITH (FORMAT csv, NULL '');
```

### Method 2: Server-Side Load

For better performance, load files directly on the database server:

```sql
-- Requires superuser or pg_read_server_files role
COPY att_scalar_devdouble (att_conf_id, data_time, value_r, value_w, quality, att_error_desc_id, details)
FROM '/var/lib/hdbpp-copy/att_scalar_devdouble__20260209T200000Z.csv'
WITH (FORMAT csv, NULL '');
```

### Method 3: Batch Load Multiple Files

Load all CSV files for a table using shell pattern expansion:

```bash
#!/bin/bash
# load_table.sh - Load all CSV files for a given table

TABLE=$1
DATA_DIR=${HDBPP_COPY_OUT_DIR:-/var/lib/hdbpp-copy}

for file in $DATA_DIR/${TABLE}__*.csv; do
    echo "Loading $file..."
    psql -d hdbpp -c "COPY $TABLE FROM '$file' WITH (FORMAT csv, NULL '');"
done
```

Usage:
```bash
./load_table.sh att_scalar_devdouble
./load_table.sh att_scalar_devlong
./load_table.sh att_conf
```

### Method 4: Continuous Loader Service

For production, use a continuous loader that watches for new `.csv` files:

```python
#!/usr/bin/env python3
"""
Continuous loader for HDB++ CSV files.
Watches output directory and loads new .csv files as they appear.
"""

import os
import time
import subprocess
import logging
from pathlib import Path

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

DATA_DIR = os.getenv('HDBPP_COPY_OUT_DIR', '/var/lib/hdbpp-copy')
PROCESSED_DIR = os.path.join(DATA_DIR, 'processed')
DB_NAME = os.getenv('HDBPP_DB_NAME', 'hdbpp')
DB_HOST = os.getenv('HDBPP_DB_HOST', 'localhost')
DB_USER = os.getenv('HDBPP_DB_USER', 'hdbpp')

# Ensure processed directory exists
os.makedirs(PROCESSED_DIR, exist_ok=True)

# Known HDB++ tables
TABLES = {
    'att_conf': 'att_conf_id, att_name, att_conf_type_id, att_conf_format_id, att_conf_write_id, table_name, cs_name, domain, family, member, name, ttl',
    'att_scalar_devdouble': 'att_conf_id, data_time, value_r, value_w, quality, att_error_desc_id, details',
    'att_scalar_devlong': 'att_conf_id, data_time, value_r, value_w, quality, att_error_desc_id, details',
    'att_scalar_devstring': 'att_conf_id, data_time, value_r, value_w, quality, att_error_desc_id, details',
    'att_array_devdouble': 'att_conf_id, data_time, value_r, value_w, quality, att_error_desc_id, details',
    # Add more tables as needed...
}

def load_csv_file(file_path, table_name, columns):
    """Load a CSV file into the database."""
    try:
        cmd = [
            'psql',
            '-h', DB_HOST,
            '-U', DB_USER,
            '-d', DB_NAME,
            '-c', f"COPY {table_name} ({columns}) FROM '{file_path}' WITH (FORMAT csv, NULL '');"
        ]
        
        result = subprocess.run(cmd, capture_output=True, text=True, check=True)
        logger.info(f"Loaded {file_path}: {result.stdout.strip()}")
        return True
    except subprocess.CalledProcessError as e:
        logger.error(f"Failed to load {file_path}: {e.stderr}")
        return False

def move_to_processed(file_path):
    """Move processed file to archive directory."""
    try:
        dest = os.path.join(PROCESSED_DIR, os.path.basename(file_path))
        os.rename(file_path, dest)
        logger.info(f"Moved {file_path} to processed directory")
    except Exception as e:
        logger.error(f"Failed to move {file_path}: {e}")

def get_table_from_filename(filename):
    """Extract table name from filename."""
    # Format: <table>__<epoch>.csv
    parts = filename.rsplit('__', 1)
    if len(parts) == 2:
        return parts[0]
    return None

def watch_and_load():
    """Watch for new CSV files and load them."""
    logger.info(f"Watching {DATA_DIR} for CSV files...")
    
    # Track processed files
    processed = set()
    
    while True:
        try:
            # List all .csv files (not .csv.current)
            csv_files = [f for f in os.listdir(DATA_DIR) 
                        if f.endswith('.csv') and not f.endswith('.current')]
            
            for filename in csv_files:
                if filename in processed:
                    continue
                
                file_path = os.path.join(DATA_DIR, filename)
                
                # Double-check it's a regular file
                if not os.path.isfile(file_path):
                    continue
                
                # Extract table name
                table = get_table_from_filename(filename)
                if not table or table not in TABLES:
                    logger.warning(f"Unknown table for file {filename}")
                    processed.add(filename)
                    continue
                
                # Load the file
                logger.info(f"Processing {filename} (table: {table})")
                if load_csv_file(file_path, table, TABLES[table]):
                    move_to_processed(file_path)
                    processed.add(filename)
                else:
                    # Failed - will retry next iteration
                    logger.warning(f"Will retry {filename} later")
            
            # Sleep before next check
            time.sleep(5)
            
        except KeyboardInterrupt:
            logger.info("Shutdown requested")
            break
        except Exception as e:
            logger.error(f"Error in watch loop: {e}")
            time.sleep(5)

if __name__ == '__main__':
    watch_and_load()
```

Run as a service:
```bash
# Install as systemd service
sudo cp hdbpp-loader.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable hdbpp-loader
sudo systemctl start hdbpp-loader
```

## Performance Optimization

### 1. Disable Indexes During Bulk Load

For large data loads, temporarily drop indexes:

```sql
-- Before loading
DROP INDEX IF EXISTS att_scalar_devdouble_time_idx;

-- Load data
COPY att_scalar_devdouble FROM '/path/to/data.csv' WITH (FORMAT csv, NULL '');

-- Recreate index
CREATE INDEX att_scalar_devdouble_time_idx ON att_scalar_devdouble (data_time DESC);
```

### 2. Parallel Loading

Load multiple tables in parallel using GNU parallel:

```bash
ls /var/lib/hdbpp-copy/*.csv | \
    parallel -j 4 'psql -d hdbpp -c "COPY $(basename {} | cut -d_ -f1-3) FROM '\''{}'\''" WITH (FORMAT csv, NULL '\'\'')"'
```

### 3. Increase Shared Buffers

For bulk loads, increase PostgreSQL's `shared_buffers` and `maintenance_work_mem`:

```sql
SET maintenance_work_mem = '2GB';
```

## Troubleshooting

### Problem: "Permission denied"

**Solution**: Ensure PostgreSQL user has read access to CSV files:
```bash
sudo chown postgres:postgres /var/lib/hdbpp-copy/*.csv
sudo chmod 644 /var/lib/hdbpp-copy/*.csv
```

### Problem: "Invalid input syntax for type"

**Solution**: Check CSV format matches table schema. Common issues:
- Wrong number of columns
- Invalid timestamp format
- Incorrect array syntax

### Problem: Files locked by FileSink

**Solution**: Only load files ending in `.csv`, never `.csv.current`. The FileSink will rename files atomically when ready.

### Problem: Duplicate key violations

**Solution**: FileSink provides at-least-once delivery. Use `ON CONFLICT` to handle duplicates:

```sql
-- Create temporary table
CREATE TEMP TABLE temp_data (LIKE att_scalar_devdouble);

-- Load into temp table
COPY temp_data FROM '/path/to/data.csv' WITH (FORMAT csv, NULL '');

-- Insert with conflict handling
INSERT INTO att_scalar_devdouble 
SELECT * FROM temp_data
ON CONFLICT (att_conf_id, data_time) DO NOTHING;

DROP TABLE temp_data;
```

## Best Practices

1. **Always use server-side COPY** for better performance
2. **Archive processed files** to avoid reloading
3. **Monitor disk space** in output directory
4. **Set up alerts** for loader failures
5. **Test with small datasets** before production deployment
6. **Use transactions** for consistency when loading multiple files
7. **Validate data** after loading (row counts, time ranges)

## Example Systemd Service

`/etc/systemd/system/hdbpp-loader.service`:
```ini
[Unit]
Description=HDB++ CSV Loader Service
After=postgresql.service
Requires=postgresql.service

[Service]
Type=simple
User=postgres
Group=postgres
Environment="HDBPP_COPY_OUT_DIR=/var/lib/hdbpp-copy"
Environment="HDBPP_DB_NAME=hdbpp"
Environment="HDBPP_DB_HOST=localhost"
Environment="HDBPP_DB_USER=hdbpp"
ExecStart=/usr/local/bin/hdbpp-loader.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
